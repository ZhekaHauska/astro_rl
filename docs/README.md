# Документация modified_astro

- [Изменения кода](changes_modified_astro.md): новые реализации, обновлённые компоненты и границы переноса.
- [Архитектура и familiarity](modified_astro.md): сигнал RSNN, порядок записи/чтения, территории, 4/20I, Whole/RFF, бюджеты и запуск.
- [Исторические отчёты](experiment_reports.md): PDF, источники, состав серий и отличия от текущих контролей.

- [Справочник конфигов](../configs/README.md) и [карта компонентов](../ARCHITECTURE.md).

Код, конфиги и исторические результаты описываются отдельно. Наличие готового конфига не означает, что его результаты уже получены: например, `mdp_dense.json` задаёт MDP-проверку Whole/RFF, но отдельного завершённого MDP-отчёта для неё здесь нет.
