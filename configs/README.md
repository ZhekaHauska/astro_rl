# Конфигурации

Актуальные MDP-запуски задаются верхнеуровневыми файлами в `experiments/`. Все ссылки в них и во вложенных компонентах задаются относительно этой папки `configs/`. `extends` наследует компонент и объединяет вложенные объекты; массивы заменяются целиком.

| Папка | Содержание |
|---|---|
| `experiments/` | конкретные MDP-серии и явные smoke-варианты |
| `architectures/` | RSNN100, RBF64, наличие availability4 |
| `models/` | выбор реализации и ссылки на память/мотор/параметры |
| `memories/` | local/full, число/перекрытие территорий, tau, calcium/EMA/Whole/RFF |
| `motors/` | pool/single и адаптивное смешивание; отдельные физические окна |
| `environments/` | single/three-goal, reward, лимит действий, режимы целей |
| `maps/` | исходные66 карт и наборы checkpoint-задач;20final/2tune на семейство |
| `parameters/` | выбранные hp по семейству/группе/варианту, без метрик результатов |
| `protocols/` | эпизоды, evaluation, seed, выбор карт, режимы абляции |
| `statistics/` | bootstrap с картами как внешними единицами репликации |

```bash
uv run python -m experiments plan --config experiments/mdp_factorial.json
uv run python -m experiments run --config experiments/smoke_pool.json --workers 2 --output results/smoke-pool
```

Входные наблюдения кодирует окружение; астроциты получают RSNN rates. Full/local и4/20I — параметры одной модели, а не копии классов. Детали и бюджеты: [modified_astro.md](../docs/modified_astro.md).

## Legacy-конфиги исходной статьи

Следующие корневые файлы сохранены без изменения условий. Они используются явным `--legacy` запуском, не актуальными MDP-конфигами выше.

| Файл | Содержание |
|---|---|
| `model.json` | Размер ALIF-ядра, входные проекции, входная проекция, prediction head; один MSE следующего входного кода |
| `memory.json` | Кальциевая память, EMA trace и inhibitory gating |
| `conditions.json`, `.csv` | 40 базовых наборов параметров: группа × модель × карта; для новой постановки выполняется tune |
| `maps.json` | Свободные клетки, стены и seed четырёх карт |
| `study.json` | Эпизоды, лимит шагов, evaluation, seed, метрики и статистический протокол |
| `tuning.json` | Начальные motor/prediction параметры и стадии поиска |

`conditions.json` задаёт параметры `run --legacy`. `tune --legacy` генерирует кандидатов детерминированно, выполняет заданные стадии и сохраняет выбранные параметры в каталоге результатов.

Архитектура SNN задаётся `model.json`; моторная голова всегда состоит из четырёх прямых Motor LIF. Обучающие параметры и расписания берутся из соответствующего условия. Настройки памяти задаются `memory.json`, затем параметры tau/gain/threshold/contrast из условия заменяют соответствующие значения.

При изменении параметров используйте новый каталог `--output`. Runner проверяет совпадение сохранённого протокола и параметров при продолжении расчёта.
